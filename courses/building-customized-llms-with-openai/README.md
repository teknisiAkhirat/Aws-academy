Dokumentasi belajar pribadi untuk course **Building Customized LLMs with OpenAI** dari Columbia University.

- [01 — Syllabus: teks asli dan terjemahan bahasa Indonesia](./01-syllabus.md)

## Cara menggunakan materi ini

1. Mulai dengan tes diagnostik pada roadmap Python agar tidak mengulang materi yang sudah dikuasai atau melompati dasar yang belum kuat.
2. Gunakan gerbang minimum di roadmap untuk menilai kesiapan mengikuti kursus; jangan menganggap seluruh roadmap Python wajib selesai sebelum kursus.
3. Bedakan kesiapan kursus Columbia dari Definition of Done pada roadmap AI Engineer. Untuk Fase 1, acuan DoD tetap script LLM API + validasi Pydantic + penanganan kegagalan validasi.
4. Ikuti prioritas dan urutan fase pada [ROADMAP_AI_ENGINEER_FINAL.md](https://github.com/teknisiAkhirat/ai-engineer-roadmap-2026/blob/main/ROADMAP_AI_ENGINEER_FINAL.md), lalu periksa posisi aktual di [TASK-LOG.md](https://github.com/teknisiAkhirat/ai-engineer-roadmap-2026/blob/main/TASK-LOG.md). Jangan gunakan README umum repo AI Engineer sebagai acuan urutan fase karena masih memuat rencana lama.
5. Gunakan Google Colab untuk latihan awal. Ingat bahwa file pada penyimpanan sementara runtime dapat hilang setelah reset; gunakan Google Drive atau unduh/unggah file jika ingin menguji persistensi.
6. Jangan menaruh API key atau token rahasia di notebook, output, atau file repository. Gunakan Secrets/Environment Variables, periksa harga provider, dan tetapkan batas pengeluaran sebelum memanggil API berbayar.

## Tentang prasyarat dan sumber

Halaman resmi Columbia+ menyebut prasyarat **basic Python programming knowledge**. Itu tidak membuktikan bahwa semua tahap dalam roadmap Python wajib diselesaikan sebelum kursus. Rincian Courseworks yang memerlukan login dan praktik yang belum dapat diperiksa secara independen harus ditandai **belum terverifikasi**, bukan dianggap sebagai persyaratan resmi.

Kursus berbayar ini merupakan pilihan belajar, bukan prasyarat untuk menjadi AI Application Engineer. Sebelum mendaftar, timbang tujuan belajar, biaya kursus dan API, serta apakah materi tersebut diperlukan untuk tahap belajar saat ini.
