# Building Customized LLMs with OpenAI

Dokumentasi belajar pribadi untuk course **Building Customized LLMs with OpenAI** dari Columbia University.

## Materi

- [01 — Syllabus: teks asli dan terjemahan bahasa Indonesia](./01-syllabus.md)

## Cara belajar

1. Baca bagian bahasa Inggris terlebih dahulu jika memungkinkan.
2. Baca terjemahan bahasa Indonesia di bawahnya untuk memahami makna.
3. Catat istilah teknis yang belum dipahami.
4. Kerjakan latihan di lingkungan yang disarankan course, yaitu Google Colab.
5. Jangan menaruh API key atau token rahasia di file repository. Gunakan Secrets/Environment Variables.
